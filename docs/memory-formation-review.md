# 长期记忆形成核对

## 形成规则

聊天历史每轮保存；正式长期记忆允许零新增。明确的持续偏好、长期目标、记住要求、
自述困难和纠正每轮即时检查。其他内容每新增 6 轮整理一次，配置项为
`MEMORY_BATCH_INTERVAL=6`，不改变会话摘要的 12/6 轮规则。

单次错误只存证据。自动薄弱点要求两道不同题目的可靠批改：高检索置信度、没有错误或拒答状态、
用户原始作答、助手明确批改结论，以及能核验的课程片段引文。模型还需确认是相同知识点、
不同题目；重复题目和改写提问不累计。用户自述以“用户自述：”标记，自动薄弱点以“练习观察：”标记。
这些门槛不能保证模型批改本身绝对正确，仍需检查真实样例。

新增的 `memory_evidence` 保存原文证据及回答可靠性，`memory_processing_states` 保存各会话处理进度。
启动时仅创建新表，不改写旧记忆。旧会话从升级后的新对话开始累计。
格式错误、输出截断或无法核验的引用会撤销本次正式记忆和进度变更；聊天历史保留，后续可重试。
同义内容合并或保持不变；明确纠正才能替换冲突事实。删除会退役关联证据，避免批量整理重新创建旧记录。

## 真实语义核对样例

前三项来自本项目已观察到的对话情形，已去掉会话标识；后三项为补充验收情形。
在独立测试会话和临时数据库中核对，避免向日常学习记录混入测试偏好。

| 输入与上下文 | 预期形成结果 |
| --- | --- |
| “HMM有什么重要的公式吗”；助手称资料未检索到完整公式 | 零长期记忆，不能记为“用户不掌握公式” |
| “什么是附加法微调”，之后反复要求再查资料 | 零薄弱点，不因为多次追问推断用户能力 |
| “刚才出过3道题，你不记得了吗” | 属于会话回忆，不形成长期学习目标或偏好 |
| “以后解释公式时都给一个例子”→“我希望公式讲解配例子” | 一条偏好；后一句补充证据，不新增同义记忆 |
| 两道不同的 CRF 归一化练习均答错，有课程依据且明确批改 | 六轮整理时可形成一条练习观察；若重复同一题则不形成 |
| “我一直分不清HMM和CRF”→“我已能区分，请忘掉这项困难” | 先记用户自述，明确遗忘后删除，不由旧证据自动恢复 |

每项同时检查 `/api/memory` 原始记录、`memory_evidence` 引文和最终 `memory_write` trace。
记录误写入、漏写入、错误合并、重复计数及旧证据恢复等情况。自动化测试使用模拟模型验证机制，
不能代替这里的语义核对；未运行真实模型时不得声称上述语义样例已通过。
